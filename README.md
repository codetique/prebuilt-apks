## Building Locally
### On Termux
```console
bash <(curl -sSf https://raw.githubusercontent.com/codetique/prebuilt-apks/main/build-termux.sh)
```

### On Linux
```console
$ git clone https://github.com/codetique/prebuilt-apks --depth 1
$ cd prebuilt-apks
$ ./build.sh
```
